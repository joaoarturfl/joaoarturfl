## Passos

1. No GitHub, crie um repositório público chamado exatamente `joaoarturfl`.
2. Envie todo o conteúdo desta pasta para a raiz desse repositório.
3. Abra a aba `Actions`.
4. Execute manualmente o workflow `Generate contribution arcade` uma vez.
5. Quando ele terminar, a branch `output` será criada e o Pac-Man aparecerá no README.
